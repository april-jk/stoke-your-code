# Design

## Overview
Stoke Your Code is a brand-first landing surface for a Git visualization product. The page should feel like a market terminal translated into a product story: dark, information-dense, sharply aligned, and visually immediate.

## Visual Theme
- Theme: dark
- Scene: a developer reviewing repository momentum late at night on a wide monitor, wanting instant signal without clicking through panels
- Register: brand
- Color strategy: committed

## Color Palette
- Background: deep graphite with subtle blue-green tint
- Surface: layered charcoal and slate panels
- Primary positive: chart green
- Primary negative: chart red
- Accent neutral: brass-gold for annotations and framing
- Copy: cool off-white with muted gray support text

## Typography
- Primary UI and body: system sans stack for terminal-grade clarity
- Secondary accent: monospace for metrics, labels, and chart metadata
- Hierarchy: oversized hero line, compressed supporting copy, compact terminal labels

## Layout
- First screen should explain the idea without requiring scrolling or interaction
- Use a dominant chart frame as the hero object
- Pair large statement text with compact explanatory rails and metric strips
- Favor ruled dividers, grids, and panel seams over floating cards

## Components
- Chart stage with candlesticks, volume bars, axis labels, and callouts
- Small metric tiles integrated into the grid rather than isolated cards
- Repository input preview styled like a terminal command bar
- Timeline rail for import, parse, render, and understand

## Motion
- Minimal and purposeful
- Slow glow and scanline drift are acceptable
- No decorative bounce, parallax, or onboarding-style choreography

## Responsive Notes
- Preserve the chart-first narrative on mobile by stacking text around the chart rather than shrinking everything into tiny panels
- Keep labels readable and reduce density before reducing contrast
