# Stoke Your Code, MVP Idea

## One-line Product
Turn a local Git repository into a K-line story of how the codebase changed over time.

## Core Principle
The product should feel understandable before it feels interactive. A user should open the page and immediately get that each candle represents a day of code movement.

## First Deliverable
Build a landing page prototype that demonstrates:
- the K-line metaphor
- daily code movement as the central visual
- a local repository import flow
- a low-interaction, high-clarity story

## MVP Story
1. Point the tool at a local Git repository.
2. Parse daily commit history into open, high, low, close, and volume.
3. Render a code-market chart that shows growth, deletion, volatility, and bursts of work.

## Why This Can Be Memorable
Most Git tools explain history as a list. This product explains history as momentum.

## Next Technical Step After This Prototype
- add a parser that reads local Git history
- compute daily candle data
- replace static mock chart data with real repository output
- let the landing page transition into a real analysis view
