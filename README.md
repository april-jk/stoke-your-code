# Stoke Your Code

Prototype landing page for a product that turns local Git history into a K-line chart of code movement.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL, usually [http://localhost:5173](http://localhost:5173).

## Current scope

- Brand-style landing page
- Trading-terminal visual language
- Static candlestick mock that explains the core concept
- Product and design context in `PRODUCT.md`, `DESIGN.md`, and `docs/idea.md`

## Next steps

- Compute daily OHLC + volume data from commit history
